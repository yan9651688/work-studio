日期：2026-11-01。依据 `PLAN.md` 一期范围实施；实际部署地址不在公开仓库中提供。

## 已交付

- Vue 3 / 原生 CSS 前台、用户中心和管理后台，明暗主题与移动抽屉。
- 站点、首页内容、渠道、模型与绑定、分组、文档、应用、技能、更新、套餐、内容规则的配置；记录分页、搜索、排序、批量启停/删除与审计。模型参数和价格提供表单编辑。
- Session 登录、注册、API Key 模型/配额限制、积分流水、CDK 兑换、人工确认充值与一次性邀请奖励。
- OpenAI、Gemini、自定义 HTTP 网关；持久任务、并发限制、重试、熔断、SSE、预扣和幂等退款；图片与视频本地存储、图片缩略图及私有签名链接。
- OpenAI 兼容图片生成、multipart 图片编辑、文本与 SSE、视频任务接口。
- 管理员可访问 `/dev/components` 检查复用组件；不再为每个基础控件建立独立包装层。
- 单个 Docker 应用容器、SQLite WAL、Nginx IP 入口、健康检查及每日在线备份。
